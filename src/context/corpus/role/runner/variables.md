## Variables

A step may name one of the project's variables as ${NAME}, such as ${LOGIN_PASSWORD}. Write it
just so where you type it, and QAzinho types its value: you never see a value, and where the
screen shows one, you read its ${NAME} in its place. When a step asks for an account or a
secret without naming a variable, use the one whose description fits. Never type a value you
guessed in its place, and never write a value down.
